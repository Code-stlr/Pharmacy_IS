# BIS Practical Task 2
**Week 2 · Components of an Information System · Maximum 2 points**

**Purpose:** Take one Information System apart into its five connected components and explain how they work together.

---

## Your Task

1. **PURPOSE** — In 2–3 sentences, explain what the system is designed to achieve.
2. **HARDWARE** — Give at least 3 examples: input, processing/storage and output. Explain each role.
3. **SOFTWARE** — Give one example of application software, system software and middleware/integration. Explain each.
4. **DATA** — Give at least 4 examples. Include structured and unstructured data and explain why.
5. **PEOPLE** — Name at least 4 roles that actually interact with, manage, support or make decisions through the system.
6. **PROCESS** — Choose one important process and describe it in 5–7 steps. Mark each step **USER** / **STAFF** / **SYSTEM**.
7. **YOUR THINKING** — Which one step would you automate or improve and why? Which one component is most critical in this system and what happens if it fails?
