# Engineering Lab 4 — Systems Analysis and Requirements
**Basics of Information Systems · 60 minutes · Maximum 2 raw points**

**Purpose:** Write user stories, functional/non-functional requirements and acceptance tests.

---

## 60-Minute Flow

| Time | Activity |
| :--- | :--- |

| **10–35 min** | Build or model the required artifact |

## Your Task

1. Write **3 user stories**.
2. Write **4 functional requirements** using *“The system shall…”*.
3. Write **2 measurable non-functional requirements**.
4. Add **acceptance criteria for 2 requirements** and assign priority.
