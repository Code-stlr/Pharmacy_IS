# BIS Practical Task 3
**Week 3 · From User Problem to IS Solution · Maximum 2 points**

**Purpose:** Think like an Information Systems analyst: start with a user problem, study existing solutions, find a gap and define what your system should do.

---

## Your Task

1. **TARGET USER — 0.3:** Choose one specific user group. Who are they and what do they need?
2. **USER PROBLEM — 0.3:** Describe one specific problem this user has. Explain why it matters.
3. **COMPETITIVE ANALYSIS — 0.4:** Find two real existing systems that solve the same or a similar problem. Compare only 3 characteristics that matter to your user/problem. What did you learn?
4. **GAP → REQUIREMENT — 0.5:** What important problem is still not solved well? Write ONE clear requirement beginning: *“The system shall…”* Explain why it matters.
5. **STRATEGIC ADVANTAGE — 0.5:** Choose **Cost Leadership / Differentiation / Focus / Innovation**. Explain exactly how your solution creates this advantage.

## Important

* Use real competitors and evidence. Do not compare irrelevant details such as logo colour or founder unless they affect the user problem.
* A requirement must say what the system must do. Example: *“The system shall display all assignments due within the next 7 days on one page.”*
* “Use AI” or “make it user-friendly” is not a clear requirement by itself.
